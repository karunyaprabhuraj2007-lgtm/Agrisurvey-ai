# AgriSurvey AI

Post-Flight Drone-Assisted Geospatial Agricultural Survey & Decision-Support Platform.

## Overview
AgriSurvey AI is a specialized post-flight data processing and analysis platform designed for drone-assisted agricultural surveys. It processes captured field imagery, extracts GIS layers, and provides AI-assisted observation verification for farm decision-making.

## Key Features
- **Mission Planner**: Manage and export drone flight plans.
- **Data Import**: Ingest flight imagery (RGB/Multispectral) and GPS/GNSS survey metadata.
- **Survey Processing**: Automated photogrammetry and geospatial alignment pipeline.
- **Survey Analysis**: High-resolution imagery viewer with AI observation suggestions and human review.
- **GIS Results**: Interactive geospatial layers (plot boundary, vegetation indices, health maps).
- **Architecture & Reports**: Clear system architecture mapping and exportable farm reports.

## Getting Started
Open `index.html` in any modern web browser or serve locally using:
